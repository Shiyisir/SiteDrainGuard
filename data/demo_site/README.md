# Synthetic demo site

This is a fictional construction-site drainage network for a reproducible demonstration. Coordinates are local planar coordinates. Elevations, pipe sizes, slopes, subcatchment areas, facility parameters, rainfall and costs are synthetic assumptions only; they do not correspond to a real project and are not engineering recommendations.

The bundled SWMM model is intended to make scenario mutation, hydraulic extraction and engineering QA observable. It is not calibrated and must not be used for design or compliance decisions.
